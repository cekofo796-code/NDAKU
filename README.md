# NDAKU
Plateforme immobilière frontend complète en HTML/CSS/JavaScript.

Fonctionne sans backend avec LocalStorage. Ouvrir index.html ou utiliser VS Code Live Server.

Pages : accueil, acheter, louer, projets neufs, détails, favoris, publier, dashboard, connexion, inscription, blog, à propos, contact.

Attention : LocalStorage n’est pas une vraie base de données serveur. Pour la production, connecter Supabase/Firebase, Storage, authentification sécurisée et modération.
